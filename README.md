# Time-Knight
Follow a young knight, suffering from amnesia, as he tries to escape the slums and reclaim a kingdom controlled by an unrelenting clan. Use time dilation to get the upper hand on your enemies and reclaim the throne.

# Local Setup and Playing Game in Editor
First, unzip everything into one folder, make sure to include
- Assets
- Packages
- ProjectSettings
- Directory.Build.props

Then, in Unity Hub, select "Add" then "Add from disk".

Select the unzipped folder, load the project, and once the editor loads navigate to:
```
Assets/Scenes/MainMenu.unity
```

And open the MainMenu Scene.

Then click play in Unity editor!
